Methods and limitations

This page documents what this independent website build does and does not claim.

Input

One workbook

The build reads the user-provided workbook migration_population_panel_40countries_2010-2022_final.xlsx from the original outputs folder. It reads the Panel, Codebook, Countries, Coverage, Key years, irregular estimates, long observations, and Source Audit sheets.

Output

Static, reviewable files

Country pages, CSV/JSON exports, the source register, local snapshots, and a manifest are written into this repository. No database or runtime API is required to browse the site.

Snapshots

What “local” means

For each distinct source URL, the build makes an independent HTTP request and stores the response when available. PDFs remain PDF files; JSON/CSV/XML/HTML responses retain their response bytes. When a host blocks local capture, the source register keeps a local pointer and the displayed Panel value links to the listed external PDF mirror. Each nonblank value in the Panel data table has a clickable evidence link.

Concepts

Do not pool unlike measures

Population is a denominator. Foreign-born is place of birth. Foreign nationals is citizenship. Irregular stock, overstayer proxies, and enforcement detections differ in concept and reference date; this site preserves them as separate fields.

Reproducibility

Build command

python scripts/build_site.py --workbook <path-to-workbook> --output . --workers 8
